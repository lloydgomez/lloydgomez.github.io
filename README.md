# Lloyd Gomez — Engineering Portfolio

Personal engineering portfolio featuring power electronics, PCB design, and robotics.

Published with GitHub Pages from main / root. Open index.html locally or serve this folder with any static HTTP server. No build step is needed.

Edit index.html for page content, app.js for project detail views, and style.css for the visual design. The other files are PCB renders, schematic views, the team Robotathon photograph, and the résumé.
